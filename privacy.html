개인정보처리방침

Hooni Film Publisher · 시행일 2026년 11월 18일

1. 이 도구에 대해

Hooni Film Publisher는 Hooni's Film Factory가 운영자 본인의 YouTube 채널에 직접 만든 영상을 올리기 위해 쓰는 내부 도구입니다. 운영자 외의 사용자는 없습니다.

2. 사용하는 Google 데이터

YouTube Data API를 통해 다음만 사용합니다.

  • 영상 업로드와 제목·설명·태그·썸네일 지정(youtube.upload)
  • 로그인한 채널의 이름과 ID 확인(youtube.readonly) — 다른 채널로 올라가지 않도록 업로드 전에 확인합니다.

다른 사람의 개인정보, 시청 기록, 구독 정보, 댓글은 읽거나 저장하지 않습니다.

3. 저장과 공유

로그인 토큰은 운영자의 컴퓨터에만 저장하며 외부 서버로 보내지 않습니다. Google 사용자 데이터를 제3자에게 팔거나 공유하지 않고, 광고에 쓰지 않습니다. 이 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 해제

언제든 Google 계정의 서드파티 앱 권한에서 Hooni Film Publisher의 접근 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

5. 문의

Hooni's film factory YouTube 채널 정보 페이지로 문의해 주세요.

Privacy Policy

Hooni Film Publisher · Effective November 18, 2026

1. About this tool

Hooni Film Publisher is an internal tool that Hooni's Film Factory uses to upload its own videos to the operator's own YouTube channels. It has no users other than the operator.

2. Google data we use

Through the YouTube Data API the tool uses only:

  • Uploading videos and setting their title, description, tags and thumbnail (youtube.upload)
  • Reading the signed-in channel's name and ID (youtube.readonly), to confirm the upload goes to the intended channel

It does not read or store anyone else's personal data, watch history, subscriptions or comments.

3. Storage and sharing

Sign-in tokens are stored only on the operator's computer and are never sent to any other server. Google user data is not sold, shared with third parties or used for advertising. Hooni Film Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Revoking access

Access can be revoked at any time from Google Account third-party permissions. After revocation the stored token can no longer be used.

5. Contact

Please reach us through the Hooni's film factory YouTube channel About page.
